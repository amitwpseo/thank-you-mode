# Changelog

## 2.0.0
- Renamed to **Thank You Mode**; all site-specific defaults removed so it works on any site.
- New tabbed settings page with a **live preview** (desktop / mobile).
- New: **background image** with overlay darkness.
- New: **schedule** (start / end date and time).
- New: **visibility rules** - always-public pages, allow other logged-in users, IP allow-list, redirect or serve-in-place.
- New: **503** response option and optional **noindex**.
- New: REST API / XML-RPC blocking can be switched off.
- New: Google Fonts on/off, custom CSS field.
- Code split into `includes/` and `assets/`; filters `tym_settings` and `tym_is_active`.
- Settings from the earlier private build (`vtc_ty_settings`) are imported automatically on first activation.

## 1.2.0 (private build)
- Color pickers, Media Library logo picker, editable blinking line / ticket stub / contact label.

## 1.1.0 (private build)
- 6 selectable designs.

## 1.0.0 (private build)
